# Node Exporter

## Description

Private host metrics for Prometheus at `node-exporter:9100` on the shared `webgateway` network.

## Setup

Ensure `webgateway` exists, copy `.env.example` to `.env`, and run `docker compose --env-file .env up -d`. There is no host-published port or Traefik route. Prometheus is preconfigured to scrape this container by name.

## Textfile collector

The textfile collector reads `*.prom` files from `./textfile` (mounted read-only at `/textfile`). Host scripts write metrics there atomically (temporary file, then `mv`); currently `n8n/scripts/check-workflow-drift.sh` writes `n8n_drift.prom` (see `n8n/README.md`, "Workflow drift check"). Create the folder as the repository owner before the first `up` (`mkdir -p node-exporter/textfile`), otherwise Docker creates it owned by root and the scripts cannot write to it. The folder is runtime data and stays ignored.

## Backup and important notes

The container uses the host PID namespace and a read-only recursive mount of `/`; run it only on a trusted host. It has no persistent data to back up; `textfile` is regenerated by the scripts that write it.
